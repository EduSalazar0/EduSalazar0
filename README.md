### 👋 About me

I'm a **Software Engineering student at Universidad de las Américas (UDLA)** who enjoys building
backends that scale: event-driven microservices, containerized deployments and secure web apps.

- 🎓 Currently working on **TITA**, my capstone project: a local web system that optimizes card-blocking
  campaigns and simulates their impact through an emulator of a financial authorizer (synthetic data only).
- 🔐 Interested in **secure software**: SSO, 2FA/OTP, JWT and identity providers like Keycloak.
- ☁️ Learning **DevOps**: Docker, Kubernetes, Jenkins and GitOps with Argo CD.
- 🌱 Always learning, always shipping.
